# 인하 자비스

인하대 생활 정보를 확인하는 크롬 사이드 패널 확장 프로그램입니다. 천원의 아침밥, 인하공지, 정석 좌석을 대상으로 합니다.

개인용으로 개발한 비공식 프로젝트이며 인하대학교가 제공하거나 운영하는 서비스가 아닙니다. 크롬 웹 스토어 등록 없이 아래 방법으로 설치할 수 있습니다.

## GitHub에서 내려받기

저장소의 **Code → Download ZIP**으로 내려받아 압축을 풀거나 `git clone`으로 복제한 뒤, 크롬에서 **압축해제된 확장 프로그램을 로드합니다**로 `extension` 폴더를 선택합니다. 별도 빌드나 API 키는 필요하지 않습니다. 자세한 단계는 아래 **크롬에 설치**를 참고하세요.

업데이트는 새 파일을 내려받거나 `git pull`로 받은 뒤 `chrome://extensions`에서 인하 자비스의 새로고침 버튼을 누르고 패널을 다시 열면 적용됩니다. ZIP으로 설치했다면 기존 설치 경로를 유지하세요.

테스트용 브라우저 프로필·스크린샷(`.artifacts/`), 환경 변수 파일, 로컬 인증 파일은 Git 추적에서 제외합니다. 인하대 마크 원본은 사용자가 제공한 `inha.svg`입니다.

## 현재 상태 — 0.7.0

기본 화면은 **정석 좌석 / 천원의 아침밥 / 인하공지** 순서로 탭을 배치합니다. 설정은 오른쪽의 작은 톱니바퀴 버튼으로 열며, 기본적으로 연결 해제·정보 삭제만 표시합니다. 주소 변경과 갱신 안내는 **고급 설정**으로 접었습니다. 좌석 오류는 실제 원인을 바로 표시하고, 나머지 오류는 **자세히**에서 상세 내용을 확인할 수 있습니다.

아침밥은 원문 문서에 포함된 모든 날짜를 표시합니다. `화요일 (10.06.)`처럼 요일이 앞에 오는 날짜, 가로로 나열된 주간 식단, 반복되는 날짜 구역, 숨겨진 요일 탭의 식단표를 읽습니다. 날짜별 메뉴는 한 항목씩 줄바꿈하고, 메뉴 칸이 비어 있으면 날짜와 `등록된 메뉴가 없어요.`를 표시합니다. 가격만 있는 `1000`, `1,000`, `1,000원` 항목은 제외합니다. 원문에서 날짜를 구분할 수 없으면 `날짜 미표시`로 표시하며, 조회 날짜를 식단 날짜로 대체하지 않습니다. 이전 버전의 직접 조회 결과는 자동 조회 시 다시 가져옵니다. 현재 탭에서 읽은 결과는 **열린 페이지 읽기**로 갱신합니다.

아침밥 식단 중 한국 시간 기준 **오늘은 연두색, 내일은 노란색**으로 메뉴 영역 전체를 채우고 날짜 앞에 `오늘`·`내일`을 표시합니다. 패널을 열어 둔 상태에서도 날짜가 바뀌면 15초 안에 표시를 갱신합니다. 연도가 명시된 과거 식단, 날짜 미표시 식단, 운영 안내에는 강조색을 적용하지 않습니다.

크롬 사이드 패널 제목과 중복되는 화면 내부의 `J` 마크와 제목은 제거했습니다. 확장 프로그램과 도구 모음 아이콘에는 사용자가 제공한 `inha.svg` 인하대 마크를 적용했습니다. 원본 비율을 유지한 16·32·48·128px PNG를 `extension/icons/`에 포함합니다. 원본을 교체할 때는 아래 브라우저 검증과 동일한 Playwright 환경에서 `node scripts/generate-icons.mjs`로 아이콘을 다시 생성합니다.

인하공지의 선택 메뉴에서 **공지사항 / 데이터사이언스학과 게시판 / 컴퓨터공학과 게시판 / SW융합대학사업단 게시판**을 전환합니다. 게시판별 주소·결과·갱신 상태를 분리하며 마지막 선택을 기억합니다. 설정에서 주소를 바꾸면 현재 선택한 게시판에만 적용됩니다. 처음 접근하는 학과 사이트는 한 번 사이트 접근 권한을 허용해야 합니다.

자비스를 열면 **정석 좌석**이 먼저 표시됩니다. 첫 사용 시 **자동 조회 시작**에서 정석 사이트 접근을 허용합니다. 이후에는 재부팅해서 연결 기록과 정석 탭이 없어져도, 자비스가 좌석 현황 탭을 비활성 상태로 열고 조회합니다. 이미 열린 같은 주소의 탭은 재사용합니다. 저장된 결과를 먼저 표시하고 실제 정석 페이지를 새로고침해 최신 결과로 바꿉니다. 정석 좌석 화면이 보이는 동안 1분마다 갱신합니다. 조회용 정석 탭은 탭 목록에 남습니다.

정석 좌석은 **제1열람실 / 통합된 제2열람실**을 표시하며, `mylibrary/seat/reading-rooms`와 공식 도서관 도메인의 내부 프레임을 읽습니다. 브라우저의 학교 로그인 상태를 사용하므로 로그인이 만료되면 **정석 로그인** 버튼이 표시됩니다. 학교에서 로그인을 마치고 좌석 현황으로 돌아오면 자동 조회를 재개합니다. 비밀번호 저장이나 자동 로그인, 좌석 예약·반납은 수행하지 않습니다. **연결 해제**나 **정보 삭제** 후에는 자동 연결을 중지하며 재실행해도 유지합니다. 다시 시작하려면 새로 조회를 누릅니다.

현재 열람실별 이용 가능 숫자가 명확하게 표시된 텍스트, 표, 접근성 라벨과 사용자가 설명한 **위쪽 남은 좌석 / 아래쪽 사용 좌석·총 좌석** 카드 형식을 읽습니다. 카드는 열람실별로 따로 추출하고 `남은 좌석 + 사용 좌석 = 총 좌석`인지 확인합니다. 분수만 있거나 합계가 맞지 않으면 빈자리로 해석하지 않습니다. `제2-1·제2-2` 숫자는 합산하지 않으며, 통합 현황을 읽지 못하면 제2열람실에 `확인 필요`를 표시합니다. 이전 버전의 분리된 열람실 캐시는 사용하지 않습니다. 사용자 설명을 재현한 문서로 검증했으며 로그인 후 실제 화면은 아직 검증하지 못했습니다.

`18 좌석 이용가능` 다음의 사용 좌석 숫자를 또 다른 잔여 좌석으로 중복 해석하던 오류를 수정했습니다. 화면에 보이는 검증된 카드, 표, 본문, 접근성 라벨 순으로 우선하며, 숨겨진 복제 화면과 갱신되지 않은 보조 라벨 때문에 값이 충돌하지 않도록 분리합니다. 같은 우선순위의 실제 좌석 값끼리 다르면 계속 오류로 표시합니다.

남은 좌석 아래에 **예약 좌석 / 총 좌석**과 **혼잡도**를 표시합니다. 혼잡도는 `예약 좌석 ÷ 총 좌석 × 100`을 소수 첫째 자리까지 반올림합니다. 원문에서 예약·총 좌석을 확인하지 못하면 남은 좌석만 표시하고 비율을 추정하지 않습니다.

설치 가능한 초기 조회 버전입니다. 별도 서버, 빌드, AI API 키 없이 실행됩니다. **실제 학교 문서의 데이터 추출은 아직 현장 검증 전**입니다. 이 개발 환경에서 학교 서버로 나가는 요청은 `EACCES`로 차단되었고, 웹 조회에서도 본교 페이지를 가져오지 못했습니다. 예제 문서로 파서와 실제 Chromium 확장 실행을 검증했습니다.

| 기능 | 구현 | 남은 확인 |
| --- | --- | --- |
| 천원의 아침밥 | 지정된 식단표의 아침밥 행 추출, 원문 날짜 표시 | 실제 식단표 구조, 이미지 여부, 운영 안내 |
| 인하공지 | 게시글 링크 추출, 중복 제거, 제목 검색, 원문 이동 | 실제 게시판 구조와 페이지네이션 |
| 정석 좌석 | 재시작 후 자동 연결, 제1·제2열람실 빈자리·혼잡도, 1분 간격 원문 갱신 | 실제 학교 로그인 유지·만료와 화면 구조 |
| 공통 | 직접 조회, 현재 탭 읽기, 출처·조회 시각, 로컬 저장, 오류 안내 | 사용자 크롬에서 실제 학교 데이터 확인 |

AI 대화·요약, 마감일 추출, 알림은 아직 구현하지 않았습니다. 웹앱·슬랙 봇·공통 백엔드도 후속 단계입니다.

## 크롬에 설치

1. 크롬 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 눌러 이 프로젝트의 `extension` 폴더를 선택합니다.
4. 도구 모음의 확장 프로그램 메뉴에서 **인하 자비스**를 클릭합니다.
5. 업데이트된 코드를 적용하려면 확장 관리 화면에서 자비스의 새로고침 버튼을 누르고 패널을 다시 엽니다.

## 사용

- 처음 한 번 **정보 불러오기**를 누르면 해당 학교 사이트에 대한 접근 권한을 크롬이 요청합니다. 권한을 허용한 출처는 이후 자동으로 조회합니다. 제목 옆 **↻** 버튼으로도 즉시 조회할 수 있습니다.
- 패널을 열거나 기능을 선택할 때 저장된 정보가 없거나 오래됐으면 자동 조회합니다. 아침밥·공지는 30분 간격으로 갱신합니다. 숨겨진 패널이나 설정 탭에서는 주기 조회를 멈춥니다. **새로 조회**로 주기와 무관하게 즉시 갱신할 수 있습니다.
- 조회에 실패하면 반복 요청을 멈추고 기존 결과와 오류를 표시합니다. **새로 조회**로 다시 시도할 수 있습니다.
- 직접 조회가 안 되면 **원문 ↗**으로 학교 페이지를 엽니다. 필요한 로그인을 학교 사이트에서 마치고 정보가 표시된 화면으로 이동합니다.
- 학교 페이지 탭에서 **자비스 아이콘을 다시 클릭**한 다음 **열린 페이지 읽기**를 누릅니다. 이 클릭으로 현재 탭 읽기 권한이 부여됩니다.
- **톱니바퀴 → 고급 설정**에서 출처를 변경할 수 있습니다. 성공적으로 읽은 탭 주소는 해당 기능의 출처로 저장됩니다.
- 아침밥·공지의 페이지 읽기는 현재 문서에 들어 있는 내용을 가져옵니다. 식단표는 숨겨진 요일 구역도 포함합니다. 이 방식의 결과는 자동으로 다시 읽지 않으므로 학교 페이지부터 새로고침하세요. 정석 좌석은 원문 페이지를 자동으로 새로고침한 뒤 읽습니다.

### 정보 표시의 한계

- 아침밥은 원문 발췌입니다. 오래된 운영 공지를 오늘의 운영 정보로 해석하지 않습니다. 이미지 식단표와 지원하지 않는 표 구조는 오류로 안내합니다. 요일을 클릭해야 서버에서 별도로 가져오는 식단은 현재 문서에 없으면 읽을 수 없습니다.
- 공지 검색은 가져온 목록(최대 100개)의 제목 검색입니다. 학교 전체 검색이나 AI 요약이 아닙니다.
- 좌석은 읽은 지 1분, 아침밥·공지는 30분이 지나면 오래된 정보로 표시합니다. 이 기준은 원문 데이터의 실제 갱신 주기를 보장하지 않습니다.
- 실패 시 기존 데이터를 유지하고 실패 메시지와 저장 시각을 표시합니다. 정보를 읽지 못한 경우를 공지 없음으로 바꾸지 않습니다.
- 자동 조회가 다른 주소로 리디렉션되면 요청을 중단합니다. 최종 정보 페이지를 브라우저에서 열어 읽거나 주소를 변경하세요.

## 권한과 저장

- `sidePanel`: 사이드 패널 표시.
- `storage`: 기능별 출처 주소와 추출된 결과를 이 브라우저에 저장.
- `storage.session`: 조회하는 정석 탭 ID를 브라우저 세션 동안 저장. 재시작 후에는 탭을 다시 찾거나 생성합니다. 자동 연결 중지 여부는 `storage.local`에 저장합니다.
- `activeTab`, `scripting`: 사용자가 실행한 학교 탭의 표시 내용 읽기.
- 선택적 사이트 권한: 조회할 때 해당 `https://…inha.ac.kr` 출처에 대해서만 요청.
- 정석 연결: `lib.inha.ac.kr`, `libapp.inha.ac.kr`, `booking.inha.ac.kr`의 페이지·내부 프레임을 읽을 권한을 연결 버튼에서 요청합니다.

아침밥·공지 직접 조회는 GET 요청이고 로그인 자격 증명을 보내지 않습니다. 정석 좌석은 일반 브라우저 탭을 통해 조회하므로 크롬이 학교 로그인 세션을 사용합니다. 확장 프로그램이 쿠키·비밀번호를 직접 읽지는 않습니다. 아침밥 날짜 확인을 위해 식단 날짜 선택 필드의 날짜 값만 추가로 읽으며, 일반 입력 내용이나 페이지 원문을 별도 서버나 AI로 전송하지 않습니다. 가져온 HTML은 화면에 삽입하지 않고 텍스트와 학교 공식 링크만 표시합니다. 현재 기기에 저장된 주소와 결과는 **설정 → 저장된 정보 삭제**로 지울 수 있습니다.

## 개발과 검증

Node.js 22 이상을 사용합니다. 런타임 외부 패키지는 없습니다.

```powershell
npm.cmd run check
npm.cmd test
```

브라우저 검증 스크립트는 별도로 설치된 Playwright와 확장 프로그램 로드를 지원하는 Chromium을 사용합니다. `JARVIS_PLAYWRIGHT_PATH`에 Playwright 패키지 경로를, `JARVIS_CHROMIUM_PATH`에 Chromium 실행 파일 경로를 지정한 뒤 `node scripts/browser-check.mjs`를 실행할 수 있습니다. 검증용 프로필과 스크린샷은 `.artifacts/`에만 생성됩니다. 사용자 기본 크롬 프로필은 사용하지 않습니다.

`node scripts/seat-connection-check.mjs`는 `.artifacts/`의 임시 확장 복사본에만 테스트용 도서관 호스트 권한을 부여해, 실제 `chrome.scripting`으로 로그인 후 경로와 내부 프레임의 예제 좌석을 읽는 과정을 검증합니다. 실제 학교 서버나 사용자 로그인은 사용하지 않습니다.

구조:

```text
extension/
  manifest.json      확장 설정과 권한
  background.js      허용된 출처 조회 요청 처리
  network.js         제한 시간·응답 크기·문자 인코딩 처리
  snapshot.js        HTML 또는 열린 페이지에서 텍스트/표/링크 추출
  breakfast.js       식단 날짜 구분과 메뉴 줄바꿈
  seats.js           현재 제1·제2열람실의 명시된 빈자리 수 추출
  seat-connection.js  정석 탭 자동 검색·생성, 중복 생성 방지
  sources.js         게시판 주소와 개별 저장 키
  core.js            출처 검증, 기능별 파싱, 검색, 저장 결과 검증
  sidepanel.*        화면과 조회 흐름
  styles.css         사이드 패널 스타일
tests/               파싱·오류·출처·캐시·네트워크 테스트
scripts/             정적 검사와 Chromium 검증
```

다음 개발 단계는 실제 학교 페이지로 식단과 공지 파서를 검증·조정하는 것입니다. 이후 검증된 조회 도구 위에 AI 대화와 요약을 연결합니다.
